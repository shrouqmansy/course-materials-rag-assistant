CS220 Databases and SQL - Lab 3: Joins (Spring 2027)

Goal
Practice INNER JOIN, LEFT JOIN and self joins in PostgreSQL 16 using the employees and departments tables.

Setup
1. Create the departments table:

CREATE TABLE departments (
    department_id INT PRIMARY KEY,
    department_name VARCHAR(50) NOT NULL,
    location VARCHAR(50)
);

INSERT INTO departments VALUES (1, 'Engineering', 'Cairo');
INSERT INTO departments VALUES (2, 'Sales', 'Alexandria');
INSERT INTO departments VALUES (3, 'Human Resources', 'Cairo');
INSERT INTO departments VALUES (4, 'Finance', 'Giza');

2. Create the employees table with these columns: employee_id (primary key), first_name, last_name, department_id (foreign key to departments), job_title, salary, hire_date and manager_id.
3. Import the file CS220_employees_sample.csv into the employees table. In DBeaver use right click on the table, then Import Data, then CSV.

Tasks
Task 1. Show the first name, last name and department name of every employee (INNER JOIN).
Task 2. Show every department with the number of employees in it. Departments with no employees must also appear, with 0 (LEFT JOIN and GROUP BY).
Task 3. Show each employee next to the name of their manager (self join). Employees without a manager must still appear.
Task 4. Show the departments located in Cairo with the average salary of their employees.
Task 5. Show the employees who earn more than the average salary of their own department.
